# 기준실 Windows 초기 설치본 (서버 연결 전)

회사 공동 견적조건 관리와 부자재 계산을 위한 Windows 10/11 x64 데스크톱 프로그램입니다.

## 다운로드

- `Gijunsil-Setup-0.1.0-x64.exe`: Windows 설치파일
- `Gijunsil-Setup-0.1.0-x64.exe.sha256`: SHA-256 확인 파일
- `desktop-login.png`: 테스트 서버에 연결한 로그인 화면
- `desktop-workspace.png`: 테스트 서버에 연결한 업무 화면

## 현재 상태

이 설치본에는 실제 회사 서버 주소가 설정되어 있지 않습니다. 설치 후 연결 준비 안내가 표시되며, 직원 로그인과 공동 자료 사용은 회사 서버 개설 및 연결 설정을 넣은 새 설치본 배포 후 가능합니다.

테스트 서버에서 로그인·권한·견적조건 검색·부자재 계산·견적 저장을 검증했고, 서버 컨테이너 재시작 후 계정과 자료 보존도 확인했습니다. 설치파일 생성 및 압축 검사는 통과했습니다. GitHub Actions Windows 실행 환경에서 설치·앱 실행·제거 검증을 통과한 뒤 게시되는 파일입니다. 실제 직원 PC 검증과 코드서명은 아직 완료하지 않았습니다. 이 파일은 서명되지 않은 초기 검토용 설치본입니다.

스크린샷은 테스트 서버의 화면이며, 현재 설치본에 회사 연결이 완료되었다는 의미가 아닙니다.
