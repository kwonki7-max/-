# 기준실 — Windows 회사 공동 업무 프로그램

직원들이 Windows 설치파일을 설치하고 로그인해 공통 견적조건을 함께 수정하고 부자재 물량·금액을 산출합니다. Electron 데스크톱 앱 + Python 3.12/Flask 공통 서버 + SQLite 구성입니다. 직원에게 로컬 작업 공간 선택이나 서버 주소 입력을 요구하지 않습니다.

**실제 회사 서버는 아직 개설하지 않았습니다.** 생성되는 설치본은 서버 연결 전 빌드이며 공동 사용 전 서버 배포와 연결 설정이 필요합니다. [Windows 설치본 안내](docs/DESKTOP.md) · [회사 서버 배포 안내](docs/SERVER.md)

아래 실행 명령은 백엔드 개발용입니다. 직원 PC에서는 Python이나 터미널 명령을 사용하지 않습니다.

## 구현 범위

- 회원가입 → 관리자 승인 → 로그인. 신규 회원은 모두 일반 사용자·승인 대기 상태입니다.
- 관리자는 서버에서 별도로 생성하며 회원 승인·이용 중지, 전체 견적 조회·수정이 가능합니다.
- 승인된 모든 사용자가 공통 기준을 조회·추가·수정합니다. 수정자·시간·변경 전후 기록 및 동시 편집 충돌 감지.
- 사용자 제공 `견적조건시트..pdf` 28개 항목의 **요약**을 초기 등록했습니다. 협의 전 3건은 별도 표시합니다. 원문 이미지·기존 지침·변경시점·담당자 등을 모두 전사한 것은 아니므로 업무 적용 전 원본 대조가 필요합니다.
- 개인 견적의 현장명·메모·여러 계산 항목 저장·재수정 및 UTF-8 CSV 다운로드. 일반 사용자는 본인 견적만, 관리자는 전체 견적에 접근합니다.
- 와이어메쉬: 시공면적 × 1.10 (PDF 2번 10% 할증).
- 커튼박스 석고보드 ㄱ자면: (너비 mm + 높이 mm) ÷ 1,000 × 길이 M. PDF 7번의 150×50 → 0.20 M²/M, 150×70 → 0.22 M²/M 예시 반영.
- 직접 입력한 단가로 계산합니다. 물량은 소수점 6자리, 금액은 원 단위 반올림, 부가세 별도. 면적·길이·단가 상한 각 1,000,000, 너비·높이 상한 각 10,000mm.
- 공통 기준 텍스트를 수정해도 공식은 자동 변경되지 않습니다. 다른 부자재 조합, 천정틀 차감, PLY 및 별도 할증은 공식 확인 후 확장해야 합니다.

## 설치 / 실행

```bash
cd /workspace/-
bash scripts/install.sh
.venv/bin/python -m pytest -q
.venv/bin/gunicorn --bind 127.0.0.1:8000 --workers 2 wsgi:app
```

클라우드 작업은 이미 격리되어 있으므로 기존 체크아웃을 사용하고, 사용자가 명시적으로 요청하지 않으면 추가 Git worktree를 만들지 않습니다. 다른 컴퓨터에서는 Python 3.12를 설치하고 체크아웃 디렉터리에서 동일 명령을 실행합니다. 설치 스크립트는 재실행해도 기존 데이터·계정·수정한 기준을 덮어쓰지 않습니다. 프로세스는 별도로 시작합니다.

## 본인 관리자 계정 생성

기본 관리자나 공용 비밀번호가 없습니다. 서버 터미널에서 다음을 실행하고 본인 이메일·이름·비밀번호를 입력하세요. **비밀번호를 채팅이나 코드에 적지 마세요.**

```bash
cd /workspace/-
.venv/bin/flask --app wsgi create-admin
```

비밀번호는 화면에 표시되지 않으며 12~128자, 앞뒤 공백 없이 입력합니다. 관리자 계정은 한 번만 생성하며 기존 일반 사용자를 자동 승격하지 않습니다. 관리자 이메일은 일반 회원가입에 먼저 사용하지 마세요. 생성 후 로그인 → 회원 관리 → 이용 승인으로 직원 가입을 승인합니다.

## 검증

```bash
.venv/bin/python -m pytest -q
node --check static/app.js
curl --fail http://127.0.0.1:8000/health
```

서버 테스트는 임시 DB를 사용합니다. 인증·CSRF·가입 승인·정지·역할 위조·다른 사용자 견적 접근 차단·공동 수정·충돌·변경 이력·계산 예시·잘못된 수치·CSV 수식 주입 방지·데이터 보존·관리자 생성·로그인 시도 제한을 검증합니다.

선택적 실제 브라우저 검증은 Playwright가 설치된 Python에서 실행합니다. 별도 임시 서버·DB·테스트 계정을 사용하며 종료 시 정리합니다. 제품 실행에는 Playwright가 필요하지 않습니다.

```bash
APP_PYTHON="$PWD/.venv/bin/python" python3 tests/browser_smoke.py
```

Chromium 기본 경로는 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 변경할 수 있습니다. 가입·승인·공동 편집·이력·계산 2종·견적 저장/수정·CSV·로그인 유지·모바일 화면을 검증합니다. 스크린샷은 `/tmp/estimate-desktop.png`, `/tmp/estimate-mobile.png`에 생성됩니다.

## 데이터 / 운영 범위

- 기본 DB: `instance/estimate.sqlite3`, 세션 서명키: `instance/session.key`. Git에서 제외되며 프로세스 재시작 후에도 보존합니다. `ESTIMATE_DATABASE`로 영구 저장소의 DB 경로를 지정할 수 있습니다. 키는 같은 디렉터리에 생성됩니다.
- scrypt 비밀번호 해시, HttpOnly/SameSite=Lax 세션, CSRF 방어, 로그인 시도 제한을 적용했습니다. 정지 계정은 기존 로그인 세션도 사용할 수 없습니다.
- 회사에서 실제 사용하려면 HTTPS 리버스 프록시·영구 디스크를 갖춘 서버에 배포하고 `COOKIE_SECURE=1`을 설정합니다. 현재 실행 명령은 개발 검증용입니다. 도메인·TLS·외부 배포·백업 자동화는 아직 수행하지 않았습니다.
- DB 백업은 SQLite backup API를 사용하고 세션키도 안전하게 보관하세요. WAL 사용 중 DB 파일 하나만 복사하면 최신 데이터가 누락될 수 있습니다. 계정·백업을 Git에 커밋하지 마세요.
- 단일 회사·단일 서버용 초기 버전입니다. 이메일 인증·비밀번호 재설정·회사별 데이터 분리·자유 계산식 편집은 미구현입니다. 회원관리 이력은 DB에 저장하며 현재 화면은 견적조건 변경 최근 200건을 표시합니다.
- 설치·시작 지침을 환경 설정 초안에 저장합니다. 초안 저장은 서버 실행이나 환경 게시를 의미하지 않습니다. 검토 후 게시해야 이후 작업에서 준비한 환경을 재사용할 수 있습니다. 새 작업에서도 프로세스가 유지된다고 가정하지 마세요.
